# 🛒 Spring MVC Product Management Application

A Spring Boot web application demonstrating product management operations using Spring MVC, Spring Data JPA, and form handling.

---

## 📌 Project Overview

This project is a Product Management web application built using Spring MVC.

The application allows users to:
- Add new products
- View all products
- Update product details
- Delete products
- Handle form submissions using MVC architecture

---

## 🧠 Concepts Covered

- Spring Boot
- Spring MVC
- CRUD Operations
- Form Handling
- MVC Architecture
- Spring Data JPA
- Hibernate
- View Rendering
